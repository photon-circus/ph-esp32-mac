## Hardware Validation

Record raw serial logs and the test firmware commit for every run.

### Canonical Board

- [ ] WT32-ETH01 wiring and external 50 MHz RMII clock are verified.
- [ ] LAN8720A PHY reset and address configuration are recorded.
- [ ] BMCR, BMSR, PHYID1, and PHYID2 reads return plausible values.
- [ ] Reversible MDIO write/read validation passes.
- [ ] Link down/up transitions report correct speed and duplex.
- [ ] DHCP lease is obtained without promiscuous mode.
- [ ] Ping, TCP echo, and sustained bidirectional traffic pass.

### Reset and MAC Filter

- [ ] 20 consecutive cold boots pass non-promiscuous unicast RX.
- [ ] 20 consecutive software resets pass non-promiscuous unicast RX.
- [ ] Runtime MAC-address change has correct register readback and filtering.
- [ ] Frames for a different unicast destination remain rejected.
- [ ] Stop and re-init does not corrupt shared reset/clock state.

### RX Exhaustion

- [ ] RX ring exhaustion reaches the expected unavailable/suspended state.
- [ ] Synchronous receive recovers and receives later unicast traffic.
- [ ] Async receive recovers and receives later unicast traffic.
- [ ] embassy-net receive recovers and receives later unicast traffic.
- [ ] Interrupt count remains below the approved storm threshold while the
  consumer is blocked.
- [ ] No power cycle or full driver reinitialization is needed for recovery.

### Secondary Hardware

- [ ] Any IP101GRI results are labeled as secondary coverage.
- [ ] Secondary-board success is not used to waive WT32-ETH01/LAN8720A gates.
